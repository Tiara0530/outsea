# 03 · 接口规范（统一 API 约定）

> 这是全队联调的「合同」。任何变更先改本文件并通知全员。
> 成员1（backend）为对外唯一入口；成员3、4 提供内部服务，由 backend 编排。

## 1. 通用约定

- 基础路径：`/api/v1`
- 协议：HTTP + JSON（UTF-8）
- 统一响应格式：

```json
{
  "code": 0,
  "message": "ok",
  "requestId": "a1b2c3d4",
  "data": { }
}
```

- 错误码约定：

| code | 含义 |
|------|------|
| 0 | 成功 |
| 40001 | 参数错误 |
| 40101 | 未授权 |
| 40401 | 资源不存在 |
| 50001 | 内部服务错误 |
| 50002 | 上游引擎/数据服务不可用 |

## 2. 核心接口

### 2.1 健康检查
`GET /api/v1/health`
```json
{ "code": 0, "data": { "status": "up", "engine": "up", "dataService": "up" } }
```

### 2.2 商品本地化
`POST /api/v1/localize`

请求：
```json
{
  "product": { "name": "保温杯", "features": ["304不锈钢", "保温12小时"] },
  "targetLanguage": "en-US",
  "targetMarket": "US"
}
```

响应（data）：
```json
{
  "title": "Insulated Stainless Steel Tumbler...",
  "bulletPoints": ["...", "..."],
  "keywords": ["insulated", "tumbler", "..."],
  "cultureNotes": ["US 市场偏好简洁直接..."],
  "provider": "ai-engine"
}
```

### 2.3 跨文化沟通
`POST /api/v1/communicate`

请求：
```json
{
  "intent": "客户询问物流时效",
  "tone": "professional",
  "targetMarket": "JP",
  "targetLanguage": "ja-JP"
}
```

响应（data）：
```json
{
  "subject": "ご注文の配送について",
  "body": "...",
  "cultureNotes": ["日式商务礼貌用语..."],
  "provider": "ai-engine"
}
```

### 2.4 出海情报检索
`POST /api/v1/intel/search`

请求：
```json
{ "category": "户外用品", "targetMarket": "US" }
```

响应（data）：
```json
{
  "trends": ["..."],
  "competitors": ["..."],
  "compliance": ["..."],
  "sources": ["..."],
  "provider": "data-pipeline"
}
```

## 3. 内部服务接口（backend ↔ 子模块）

### ai-engine（成员3 提供，backend 调用）
- `POST /engine/localize`：入参与 `localize` 的 product/target* 一致，返回 data 部分。
- `POST /engine/communicate`：入参与 `communicate` 一致，返回 data 部分。
- `GET /engine/health`

### data-pipeline（成员4 提供，backend 调用）
- `POST /data/intel/search`：入参与 `intel/search` 一致，返回 data 部分。
- `GET /data/health`

> 后端负责把这些内部服务封装为对外接口，并统一错误码与超时重试。

## 4. 联调顺序

1. 成员1 先实现 mock 返回，让前端能并行联调。
2. 成员3、4 各自把内部服务按上面入参/出参实现。
3. 成员1 把 mock 替换为真实调用，做端到端联调。
