# ai-engine/ —— 成员3 · AI 匹配引擎

> 职责：匹配打分（成本/利润/效率/兼容）+ 组合推荐 + 理由生成。

## 我的工作（一句话）
实现匹配打分引擎：给定需求 + 候选供给，输出排序 + 四维打分 + 理由 + 推荐组合。

## 目录结构（建议）
```
ai-engine/
├── README.md
├── requirements.txt
├── app/
│   ├── main.py            # /engine/match /engine/health
│   ├── scoring/           # 四维打分
│   │   ├── cost.py        # 成本
│   │   ├── profit.py      # 利润
│   │   ├── efficiency.py  # 效率
│   │   └── compatibility.py # 兼容性
│   ├── recommend.py       # 组合推荐
│   └── llm.py             # 模型接入（理由生成，可选）
└── samples/               # 输入输出示例
```

## 依赖与被依赖
- 依赖：成员1 引擎接口约定（`docs/03-接口规范.md` 第 4 节）。
- 被依赖：成员1 调用；成员2 展示。

## 验收标准
- [ ] 给定需求 + 候选供给，稳定输出排序 + 打分 + 理由。
- [ ] 兼容性判断正确（如 CPU/主板匹配）。

## 任务清单
- [ ] 定义四维打分规则（成本/利润/效率/兼容）
- [ ] 实现 `/engine/match` 打分排序
- [ ] 实现组合推荐（整机多部件）
- [ ] 生成匹配理由（规则或模型）
- [ ] 保证输出标准 JSON、容错
- [ ] 调优 + 准备演示样例

## 怎么开始
先用「甲 + a,b,c,d,e」造 3–5 组「需求+供给→理想匹配」示例（放 `samples/`），据此定打分规则，再写代码，用示例反复验证。
