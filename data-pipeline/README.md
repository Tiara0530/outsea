# data-pipeline/ —— 成员4 · 数据/评测

> 职责：供需样例数据 + 匹配效果评测。

## 我的工作（一句话）
准备供需样例数据（含演示主线「甲 + a,b,c,d,e」），并写评测脚本评估匹配是否合理。

## 目录结构（建议）
```
data-pipeline/
├── README.md
├── requirements.txt
├── app/
│   ├── main.py            # /data/samples /data/eval /data/health
│   ├── eval.py            # 评测脚本
│   └── metrics.py         # 评测指标
├── data/
│   ├── demands.json       # 需求样例
│   └── supplies.json      # 供给样例（a,b,c,d,e）
└── scripts/
```

- 被依赖：成员1 调用；成员3 用样例验证打分。
