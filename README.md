# Outsea 客商对接智能系统

> 知乎黑客松 S3 · 湾区共创季 —— 方向 3「出海新航路」
> 供需双方发布需求/上架资源，AI 按成本、利润、效率、兼容性匹配最合适的客商，并撮合建立连接。

---

## 一句话定位

需求方发需求、供给方上资源，AI 自动匹配最优客商并撮合对接。

## 三大核心功能（对应赛道关键词）

| 功能 | 关键词 | 说明 |
|------|--------|------|
| 📝 需求发布 | 对外贸易 | 需求方发布：产品、规格、数量、收货地、预算、交期 |
| 📦 供给上架 | 对外贸易 | 供给方上架：资源/商品、规格、发货地、价格、MOQ、库存、交期 |
| 🤝 AI 匹配撮合 | 跨境协作 | 按成本/利润/效率/兼容性打分排序，推荐组合，建立连接（意向单） |

## 演示主线

甲（需求方）要采购 N 台主机 → 系统匹配出 a（主板）、b（显卡）、c（CPU）、d、e → 甲勾选 a、b、e → 系统建立连接、生成意向单，完成对接。

## 技术栈

| 层 | 选型 |
|----|------|
| 前端 | React + Vite + TypeScript |
| 后端 | Python FastAPI（数据模型 + API + 编排） |
| 匹配引擎 | 大模型 API（Token 补贴）+ 打分规则 |
| 数据/评测 | 供需样例数据 + 匹配效果评测 |
| 部署 | 知乎 AI Works |

## 快速开始

1. 每人先读 `docs/02-分工说明.md` + 自己工作区 `README.md`。
2. 只在自己工作区提交代码，公共改动走 PR。
3. 跨模块协作以 `docs/03-接口规范.md` 为准。

## 提交与验收

见 `docs/04-提交指南.md`。核心：**发布/上架 + 匹配推荐 + 建立连接 在一个应用里跑通，Demo 视频 + 材料齐全，按时提交。**
