# Outsea 出海智能助手

> 知乎黑客松 S3 · 湾区共创季 —— 方向 3「出海新航路」
> 面向中小外贸卖家与跨境团队的一站式 AI 出海工具，解决「语言、文化、情报」三大出海门槛。

---

## 一句话定位

把一句中文商品介绍，变成「多语言、懂当地文化、带市场情报」的出海落地内容。

## 三大核心功能（对应赛道关键词）

| 功能 | 对应关键词 | 说明 |
|------|-----------|------|
| 🛍 商品本地化引擎 | 对外贸易 | 输入中文商品信息 → 输出多语言、符合目标市场习惯的标题/五点描述/SEO 关键词（本地化改写，非机械翻译） |
| 💬 跨文化沟通助手 | 跨境协作 | 多语言邮件/客服话术生成，语气按目标市场本地化（欧美直接、日韩礼貌、中东合规） |
| 📡 出海情报雷达 | 跨文化适配 | 基于 RAG 的目标市场趋势 / 竞品 / 合规要点速查 |

## 技术栈

| 层 | 选型 |
|----|------|
| 前端 | React + Vite + TypeScript |
| 后端 | Python FastAPI（统一编排 + REST API） |
| AI 引擎 | 大模型 API（官方 Token 补贴）+ 知乎 CLI，Prompt 工程 |
| 数据/RAG | Python + 向量检索（嵌入 + 向量库） |
| 部署 | 知乎 AI Works 部署 |

## 五人分工速览

| 成员 | 角色 | 工作区 | 核心交付物 |
|------|------|--------|-----------|
| 成员1 | 组长 · 后端架构 | `backend/` | 统一 API、编排、联调 |
| 成员2 | 前端工程师 | `frontend/` | 三个功能页 UI |
| 成员3 | AI/LLM 工程师 | `ai-engine/` | Prompt 库、本地化/沟通引擎 |
| 成员4 | 数据/情报工程师 | `data-pipeline/` | 情报数据 + RAG 检索 |
| 成员5 | QA/DevOps/交付 | `deploy/` | 部署、Demo、提交材料 |

> 详细职责、依赖关系、验收标准见 [docs/02-分工说明.md](docs/02-分工说明.md)。

## 快速开始

1. 每人先读：`docs/02-分工说明.md` + 自己工作区的 `README.md`
2. 每人只在自己的工作区目录提交代码，公共改动走 PR
3. 跨模块协作以 `docs/03-接口规范.md` 为准

## 进度跟踪

- 每个人的任务清单用 GitHub Issue 管理（模板见 `.github/ISSUE_TEMPLATE/`）
- 每日在 `docs/05-日程与里程碑.md` 的进度表打勾
